# DAY 17 — TCP / UDP

## 1. Objectives

The objectives of Day 17 are:

- Understand TCP
- Understand UDP
- Understand TCP 3-way handshake
- Understand SYN, SYN-ACK and ACK
- Understand network ports
- Understand sockets
- Compare TCP and UDP
- Understand HTTP over TCP
- Understand DNS over UDP
- Observe TCP and UDP packets using Cisco Packet Tracer
