# Day 8 - Linux Processes

## Objectives

Learn how Linux processes work and how to inspect and manage them.

## Commands Learned

- ps
- ps aux
- ps -ef
- top
- htop
- pgrep
- kill
- pkill

## Important Concepts

### PID

Process ID used to identify a process.

### PPID

Parent Process ID.

### Parent and Child Processes

A process can create another process.

Example:

```text
Parent Process
      |
      +---- Child Process
